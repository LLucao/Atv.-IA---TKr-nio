**TKrânio - Sistema de Inteligência Artificial para TI**



**Fala aí galera! Esse meu projeto foi desenvolvido como parte de um exercício do meu curso de Desenvolvimento de Sistemas (SENAI)**



**A ideia que foi passada, foi criar um chatbot inteligente do zero — tendo tela de login, alternância de tema (claro/escuro) e uma IA simulada (Sem API) focada em responder dúvidas e dar exemplos práticos sobre tecnologia e programação!**



**O que o sistema faz?**



\- Tela de Login: Sistema de autenticação simples com usuário e senha para liberar o acesso ao chat.

\- Chat Interativo: Uma interface moderna estilo ChatGPT onde você pode conversar, tirar dúvidas e pedir exemplos de código.

\- IA Especializada em TI: O sistema reconhece várias formas de cumprimento (como "Opa", "Eaí", "Oi") e responde perguntas sobre Python, Java, HTML, CSS, JavaScript, SQL, Git e Linux\*\*.

\- Geração de Exemplos: Se você pedir um exemplo (ex: \*"me dê um exemplo em Python"\*), a IA traz blocos de código formatados para facilitar o estudo.

\- Modo Claro e Escuro: Botão funcional no topo para alternar entre o tema escuro (preto e vermelho) e o tema claro (preto e branco)





**Tecnologias e Bibliotecas Utilizadas**



Para construir essa IA, utilizei aplicações visuais (frontend) e o servidor (backend):



\- Python (com o framework \*\*Flask\*\* para gerenciar as rotas e a inteligência do chat)

\- Flask-Cors (para permitir a comunicação entre o front e o back)

\- HTML5 e CSS3 (para a estrutura das telas)

\- Tailwind CSS via CDN (para estilização rápida e design moderno)

\- JavaScript (Vanilla) (para manipular o login, o envio de mensagens e a troca de temas)
